Manual de Marca SalentoCoffee V 2.0" y el "SalentoCoffee Framework (versión 2.0)", hay algunos detalles adicionales y variaciones técnicas que son importantes para la precisión total de la marca.
Aquí tienes el desglose completo y verificado según las fuentes:
1. El Gradiente Principal (Los 4 Pilares)
El manual especifica que los colores primarios del gradiente deben usarse en este orden exacto:
• Core 1 (Violeta): #A40EBB
• Core 2 (Morado): #6607DE
• Core 3 (Azul Eléctrico): #007AFF
• Core 4 (Cyran/Cyan): #5AC8FA
Nota importante: En el documento del Framework, se menciona un color adicional en la lista del gradiente llamado Ultrasonic Blue (#3929CC), que se sitúa cromáticamente entre el violeta oscuro y el azul.

3. Colores de Sistema (System Feedback)
Estos colores tienen una "personalidad SalentoCoffee" y también cuentan con sus variantes de intensidad:
• Success (Éxito): Vivid #00D9A3, Deep #00A67E, Soft #D1FAE5.
• Warning (Aviso): Vivid #FB923C, Deep #EA580C, Soft #FFEDD5.
• Error: Vivid #FF2D55, Deep #E0264A, Soft #FEE2E2.
4. Neutros de Base
• White: #FFFFFF.
• Ghost (Gris funcional): #F2F2F7.
• Alice (Gris azulado): #E2E8F0.
• Off Black (Texto principal): #1D1D1F.
5. Aplicaciones Técnicas en Botones
El manual y el kit de estrategia especifican códigos para elementos de acción:
• Botón Primario (Azure): Se usa el azul sólido #007AFF.
• Botón Gradiente (CTA Hero): Se utiliza un gradiente específico que va de Violeta a Morado (#A40EBB → #6607DE) con texto en blanco.
• Botón de Cierre (CTA Final): En el Bloque 8 del Home, el botón es blanco con texto morado sobre un fondo de gradiente suave.
6. Estética Visual y Estilo
Además de los colores, los archivos definen el "look & feel":
• Glassmorphism: Uso de cristal translúcido con desenfoque (backdrop-filter: blur) y sombras suaves.
