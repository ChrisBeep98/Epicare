# 04 · Dirección Visual, Decisiones y Alcance

## Dirección Visual y Estética
- **Modo:** Dark mode from day 1.
- **Background Base:** `#2F3437`
- **Accent Principal:** `#35BBFD` (Azul)
- **CTA / Urgencia:** `#F26023` (Naranja)
- **Tipografía Display:** `Geist` — headlines grandes, estilo editorial.
- **Tipografía Datos:** `Geist Mono` — métricas, números, KPIs.
- **Dirección Estética:** Tech minimalism — Linear / Vercel family.
- **Visuales Hero:** Tipografía + composiciones de datos (sin screenshots aún).
- **Ilustraciones:** Skill `go-ams-visuals` disponible para assets.

> **⚠️ Restricción Crítica:** Sin screenshots disponibles en fase de planeación. El hero debe funcionar con tipografía editorial, composiciones numéricas y posiblemente ilustraciones del sistema.

## Decisiones Abiertas (Pendientes de Resolución)
1. **D1 (Bloqueante):** URL definitiva de la landing (`ams.epicareinsurance.com`, subdirectorio `/join`, o dominio separado). Impacta SEO y routing.
2. **D2 (Bloqueante):** El CTA, ¿va a formulario propio o a link externo (Calendly, Contracting)? Impacta necesidad de backend.
3. **D3 (Confirmar):** La fecha Jul 14 2026, ¿es pública o solo interna?
4. **D4 (Estratégico):** Idioma de la landing (inglés, español, o ambos).
5. **D5 (Nice to have):** Assets de video o motion para el hero.
